# Education

A collection of coursework and scripting exercises in Bash, Windows batch, and PowerShell.

## Projects

| Folder | Exercise | Supporting material |
| --- | --- | --- |
| [Bash](Bash/) | [Password checker](Bash/pass_check.sh): an interactive menu that checks password length and character types. | Six screenshots documenting the exercise. |
| [Batchfiles](Batchfiles/) | [System information script](Batchfiles/SystemInfoScript_PUBLIC.bat): displays system details, network information, and running processes on Windows. | [Original assignment notes](Batchfiles/README.txt). |
| [Powershell](Powershell/) | [File search tool](Powershell/SearchThruPowershell.ps1): an interactive search with configurable keywords, search folder, output file, and search depth. | Seven screenshots documenting the exercise. |

## About this collection

These files preserve the coursework as submitted, including the original code, comments, and assignment notes. Screenshots remain alongside their related scripts.

The scripts are learning exercises. Their behavior and limitations reflect the original submissions; the password checker uses the exercise's own rules rather than a general security standard.

## Before running an exercise

- Use Bash for the Bash exercise and Windows for the batch and PowerShell exercises.
- Read the script and its original notes before running it.
- The batch script displays information about the local computer and network. Its original notes describe administrator access during testing.
- The PowerShell search writes to the selected output file and replaces that file's existing contents when a search starts. Choose a dedicated results file.
